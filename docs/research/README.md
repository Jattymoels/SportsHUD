# Research notes

Background gathered on 2026-11-11 before the spec was written. The spec in `docs/spec.md` says what to build; these notes say why, and what the platform allows.

| File | What it holds | Read it when |
| --- | --- | --- |
| [platform-notes.md](platform-notes.md) | Meta Ray-Ban Display hardware, the web app platform, device APIs, tooling, how to load and share an app, reference projects | Before writing any code that touches the display, input or sensors |
| [landscape.md](landscape.md) | Competitors, prior art, market and install-base numbers, platform risks | Before making product or positioning decisions |
| [feature-ideas.md](feature-ideas.md) | Techniques for the hard behaviours, data sources, and ideas parked for later checkpoints | When designing a build, or looking for what comes after Checkpoint 1 |
| [hardware-and-market.md](hardware-and-market.md) | Added 2026-11-12, after the prototypes: what each kind of glasses can and cannot do, which kits to get and in what order, which of the limits in these notes can be broken through, and what stands between the prototypes and a product | Before buying hardware, choosing a platform, or deciding what to build next |

## How reliable this is

- Facts were checked against the linked sources on 2026-11-11. The platform is changing quickly, so re-check Meta's documentation before relying on a capability.
- Anything marked **unverified** came from general knowledge, not a checked source.
- Sales figures are third-party estimates, not Meta's reported numbers.
